# Maze Adventure: Fantasy RPG 🎮

เกมเขาวงกตผจญภัยเพื่อฝึกทักษะการเขียนโปรแกรมเบื้องต้น

## รายละเอียดเกม
เกมเขาวงกตจำนวน 3 ด่าน ได้แก่
- ด่านที่ 1 HTML
- ด่านที่ 2 CSS
- ด่านที่ 3 PHP

ผู้เล่นต้องเดินผ่านเขาวงกต เก็บกุญแจเพื่อเปิดทางออก และตอบคำถามเพื่อผ่านไปยังด่านถัดไป

## วิธีเล่น
1. ใช้ปุ่มลูกศรหรือ W A S D เพื่อเคลื่อนที่
2. เดินไปเก็บกุญแจ
3. เดินไปยังประตูทางออก
4. ตอบคำถามให้ถูกต้องเพื่อรับ 10 คะแนนและผ่านด่าน
5. ผ่านครบทั้ง 3 ด่านเพื่อชนะเกม คะแนนเต็ม 30 คะแนน

## ระบบเสียง
- เสียงเดินตัวละคร
- เสียงเก็บกุญแจ
- เสียงตอบคำถามถูก
- เสียงตอบคำถามผิด
- เสียงชนะเกม

## เทคโนโลยีที่ใช้
- HTML
- CSS
- PHP
- JavaScript
- XAMPP

## วิธีติดตั้งและเปิดเกม
1. ติดตั้งโปรแกรม XAMPP บนคอมพิวเตอร์
2. ดาวน์โหลดโปรเจกต์จาก GitHub โดยเลือก Code → Download ZIP
3. แตกไฟล์ ZIP และนำโฟลเดอร์เกมไปไว้ใน `C:\xampp\htdocs\`
4. ตั้งชื่อโฟลเดอร์เกมเป็น `MazeAdventure`
5. เปิด XAMPP Control Panel แล้วกด Start ที่ Apache
6. เปิด Chrome แล้วเข้า `http://localhost/MazeAdventure/index.php`
7. กดเริ่มเกมเพื่อเล่น

**หมายเหตุ:** เกมนี้ใช้ PHP จึงไม่สามารถเล่นโดยตรงผ่าน GitHub Pages ได้ ต้องใช้เว็บเซิร์ฟเวอร์ที่รองรับ PHP
